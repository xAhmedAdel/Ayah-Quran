# Ayah Phase UI-0 — Interactive Visual Prototypes

Self-contained, editable HTML/CSS/JS visual prototypes implementing the exact **Al-Mushaf Al-Hadith** design tokens, Arabic RTL / English LTR layouts, and Light / Dark themes.

## Files

1. **`ayah-redesign-prototype.html`**
   - Interactive mobile prototype covering all **8 core redesigned screens**:
     1. Home Sanctuary
     2. Quran Hub (Surahs / Juz / Bookmarks)
     3. Mushaf Page Reader (interactive ayah tap highlight + floating Ayah Action Pill)
     4. Audio Studio (Reciter cards, filters, download progress bars)
     5. Now Playing (Medallion, seek bar, transport controls, repeat/sleep/speed)
     6. Prayer Times & Adhan (Emerald Sanctuary countdown hero, timetable, Sunrise separation, reliability strip)
     7. Wallpapers Studio (Sticky live phone-frame preview + 5 live interactive template swatches + font slider + destination Apply bar)
     8. Unified Settings Hub (Interactive Light/Dark cards, Arabic/English toggle, grouped preference rows, BiDi-isolated version)
   - Toggle **Interactive Phone** vs **All 8 Screens** overview, **Arabic RTL** vs **English LTR**, and **Light** vs **Dark** mode live.

2. **`creative-directions-board.html`**
   - Side-by-side interactive comparison of **Direction A (Al-Waraq)**, **Direction B (Al-Bayan)**, **Direction C (Al-Noor)**, and **Recommended Direction D (Al-Mushaf Al-Hadith)** with live color swatches, RTL/LTR switching, and Light/Dark switching.

## How to Open

Open either HTML file directly in any modern browser (Chrome, Edge, Firefox, Safari). Uses Google Fonts (`Amiri` + `IBM Plex Sans Arabic` + `Inter`) when online and gracefully degrades to local serif/sans-serif fonts offline.
