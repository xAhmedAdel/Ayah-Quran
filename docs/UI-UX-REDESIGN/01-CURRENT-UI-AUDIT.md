## 3. Accessibility, RTL/LTR & Edge-Case Audit

1. **Touch Targets**: `MushafPageReaderScreen` top actions and `AudioScreen` surah row actions use `IconButton` (48dp compliant), but `CityPickerDialog` rows and `HomeScreen` `TextButton`s have tight vertical hit spacing; `PrayerSettingsScreen` 4-chip rows squeeze touch widths below ~76dp with multi-word Arabic labels.
2. **Contrast & Color-Only States**:
   - `MushafText` ayah highlight (`secondary.copy(alpha = 0.15f)` = GoldDeep at 15% on Cream) has very low visual salience on sunlit screens.
   - Disabled Bookmark and Play icons in `MushafPageReaderScreen` look broken rather than contextually explained.
   - Good existing practice to preserve: `PermissionsDashboardSection` and `WallpapersScreen` pair icons with text (never color alone).
3. **Screen Reader (`contentDescription`) Bugs**:
   - `AudioScreen.kt:199` & `NowPlayingScreen.kt:177`: Play/Pause icon hardcodes `R.string.audio_pause` even when paused.
   - `QuranScreen.kt:65`, `AdhanLibraryScreen.kt:130`: Search icon has `contentDescription = null` (acceptable since field has placeholder, but clear buttons will need explicit CDs).
   - `PrayerOnboardingScreen.kt:276`: Status icon relies on adjacent text, which is good once the misleading `RadioButtonUnchecked` icon is replaced.
4. **Font Scaling (`1.3x`–`2.0x`)**:
   - `NowPlayingScreen` uses non-scrolling `Row`s for 3 sleep chips and 4 speed chips -> will clip/wrap badly at 1.5x font scale.
   - `PrayerSettingsScreen` uses 4 equal-weight `FilterChip`s in a `Row` -> guaranteed text truncation at 1.3x+ font scale.
   - `NavigationBar` with 6 tabs already clips/crowds at 1.0x font scale and breaks completely at 1.3x+.
5. **RTL & BiDi Defects**:
   - Version number `1.0.0-beta.6-debug` reverses visually to `beta.6-debug-1.0.0` in Arabic RTL (needs `\u2066...\u2069` LRI/PDI isolation).
   - `surah:ayah` (`17:40`), download counts (`12 / 286`), page ranges (`1–7`), and countdowns (`02:14:09`) lack explicit LTR isolation.
   - `ReaderScreen` prev/next surah icons contradict `MushafPageReaderScreen` RTL arrow convention.
6. **Dark Mode & Handover Gaps**:
   - Handover package contains zero dark-mode screenshots and zero English LTR screenshots; `AyahDarkColors` (`Color.kt:64-92`) is well-structured with green-tinted `surfaceContainer*` tones, which must be preserved and elevated in the redesign.

   - `PrayerTimesUiTest.kt`: Hardcodes `"القاهرة · مصر"` single-Text concatenation; expects all 5 prayers + sunrise + `prayer_sunrise_note` + all 4 settings sections composed simultaneously without scrolling.
3. **Shared `@Before` Hook (`AudioPlaybackEntryPoint.clearRestore()`)**: Used by `AppUiTest`, `AudioTabUiTest`, and `MushafPageReaderUiTest` — must be preserved intact.
